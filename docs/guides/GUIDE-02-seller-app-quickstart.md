# GUIDE-02: Seller App Quickstart

## 1. Executive Summary

This guide helps merchants set up the Frictionless Seller app (Shadow) and broadcast their first deal in under 15 minutes. It covers account setup, store verification, deal creation, and redemption.

The Seller app is designed to be simple: view demand, create deals, redeem fast.

## 2. Install & Verify

1. Download **Frictionless Seller (Shadow)**
2. Sign in with your phone number
3. Verify your OTP code
4. Confirm your store location on the map

## 3. Create Your First Deal

1. Tap **Create Deal**
2. Enter discount and duration
3. Choose radius (recommended: 300m)
4. Tap **Publish**

## 4. Watch the Heatmap

- The heatmap shows nearby activity in real time
- Blue = low activity, Yellow = medium, Red = high
- Use spikes to time flash deals

## 5. Redeem a Deal (SafeColor Verification)

1. Tap **Redeem** to open the scanner
2. Scan the buyer's QR code
3. Verify the matching color code
4. Confirm the redemption

## 6. Tips for Better Performance

- Post deals during peak foot traffic
- Start with short time windows (1-2 hours)
- Use clear, simple discounts (e.g., “30% off tops”)

## 7. Troubleshooting

| Issue | Fix |
| --- | --- |
| No activity on heatmap | Check GPS permissions and radius |
| QR not scanning | Improve lighting and clean camera lens |
| Deal not showing | Confirm deal status is Active |
